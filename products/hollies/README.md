# Hollies

A personal self-improvement app: see where your time goes, keep a daily top 3, hold reading, exercise and study habits, and get back on track when a day slips. Snapshot 2026-11-16.

- **Stack:** one Flutter codebase for Android, iOS and the web; data stays on the device (no account, no sync yet).
- **Status:** MVP built; the web app is published and can be installed on a phone's home screen. Native store builds not started.

## Features

| Area | Features |
| --- | --- |
| Time log | One-tap timer for Work, Reading, Exercise or University; today's log and total |
| Top 3 | Up to three things for today with impact and due date; everything else waits in Later |
| Habits | Daily reading, exercise and study targets with a week strip and streaks |
| Insights | Day and week view: time by category, time per day, habits, streaks, on-track score, log export as CSV |
| Staying on track | Daily on-track score, evening check-in, identity lines and plan-your-day card in the morning, weekly review with one experiment, in-app nudges (at most 3 a day, never in quiet hours) |
| General | English and Vietnamese, light and dark theme, phone and wide-screen layouts |

## Delivered

Scaffold and local storage, time log, priorities, habits, insights, evening check-in and on-track score, morning section, weekly review, nudges, README with screenshots and an EN/VI user guide, web app with its own icon (2026-11-15 to 2026-11-16).
